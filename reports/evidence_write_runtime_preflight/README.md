# Runtime Evidence Write Preflight Reports

This directory is for local ignored Phase 2.88 preflight reports.

Reports are diagnostic artifacts only:

- no writer invocation
- no DB writes
- no parser execution
- no file copy
- no NAS scan
- no OpenSearch / Qdrant / MinIO writes
- no Agent answer integration
- no repair / cleanup / backfill / reindex / delete / migration

Real JSON reports are ignored by default and must not be committed.
