# NAS Evidence Preflight Reports

This directory is reserved for local Phase 2.84a evidence-write preflight dry-run reports.

Real preflight report JSON files are local machine artifacts and must stay ignored. They may contain run identifiers, approval state, dry-run document references, or operational diagnostics.

Phase 2.84a reports do not authorize `documents` / `chunks` writes, parser execution, NAS copy, DB writes, index writes, object-store writes, Agent answer integration, or production rollout.
